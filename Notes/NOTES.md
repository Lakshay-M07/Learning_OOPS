# Class is a blueprint for creating objects. 
# It defines a set of attributes and methods that the created objects will have.

# Objects are instances of a class. 
# They are created based on the blueprint provided by the class and can have their own unique values for the attributes defined in the class.

# Four pillars of OOPS - Encapsulation    Abstraction
#                        Polymorphism     Inheritance

# Encapsulation - It is about keeping some information (data) safe and only letting it be changed or looked at in specific ways. Basically apne data ko safe rakhna hai taaki koi aur bahar se access na kar sake apni class ke andar

# Polymorphism - It means having many forms. Matlab ek he cheez different tasks perform kar paa raha hai. Like a phone having multiple qualities having a calculator and a camera.

# Inheritance - When 1 class inherits some feature from another class this phenomena is known as inheritance. Ek class jab doosri class se cheez transfer karti hai usko inheritance kahete hai.
# ~ Like a child inherits some qualities from parents.

# Abstraction - When we only see the essential part of our code and hides the rest is the process of Abstraction. Matlab bas kaam ki chiz dikhana aur sab chupa lena.
